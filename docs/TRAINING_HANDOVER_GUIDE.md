# Training and Handover Guide

## Audience
- Communications lead
- Content editors
- Technical maintainer

## Training Agenda
1. CMS basics
- Logging in, editing content types, publishing workflow
- Updating pages, blog posts, events, and resources

2. Website operations
- Managing navigation labels and contact details
- Managing social links in site settings
- Reviewing form and newsletter submission routing

3. Troubleshooting
- Common content issues
- Broken links and media checks
- Escalation and support contacts

## Handover Checklist
- Source code repository access transferred
- Environment variables documented and validated
- CMS roles and permissions configured
- Deployment access and rollback steps documented
- QA report delivered and approved

## Admin Runbook
- Weekly: content review and link validation
- Monthly: dependency updates and security review
- Quarterly: performance and accessibility audit
