# Staff Training Guide

## Who Uses What
- Communications lead: homepage messaging, blog posts, events, testimonials.
- Content editor: programs, resources, team profiles, about page content.
- Technical maintainer: Studio access, environment variables, deployments, and troubleshooting.

## Daily Workflow
1. Open the Sanity Studio and sign in.
2. Pick the document type you want to update.
3. Edit the text, image, or file fields.
4. Preview your changes inside Sanity if needed.
5. Click `Publish`.
6. Refresh the website and confirm the page looks correct.

## What To Edit In Sanity

### Homepage
Use the `Homepage` document to manage the main landing page. Staff can now update:
- Hero eyebrow, title, subtitle, and hero image
- Vision card title and text
- Mission card title and text
- Impact section title, subtitle, and impact stats
- Stories section title and subtitle
- Call-to-action title, text, button labels, button links, and CTA background image

### Blog
Use `Blog Post` for news, stories, and updates.
- Add a title, slug, excerpt, body, category, featured image, publish date, and SEO fields
- Select an author from `Team Member`

### Events
Use `Event` for upcoming activities.
- Add the title, slug, date, location, description, and image

### Programs
Use `Program` for program pages.
- Add the title, slug, summary, activities, impact metrics, funding goal, amount raised, and image

### Resources
Use `Resource` to upload PDFs and downloadable documents.
- Add the title, choose a category, and upload the file

### Team
Use `Team Member` for staff or board profiles.
- Add the name, role, bio, display order, and photo

### Testimonials
Use `Testimonial` for quotes shown on the homepage.
- Add the speaker's name, role, and quote

### Site Settings
Use `Site Settings` for organization-wide contact information.
- Update the organization name, email, phone, address, and social media links

## Publishing Checklist
- Check spelling, names, and dates
- Confirm images are the right ones
- Make sure buttons and document links open correctly
- Publish the change
- Refresh the live page and verify it displays correctly

## Common Mistakes To Avoid
- Do not leave required fields empty
- Do not change a slug after a page is already shared unless a technical maintainer confirms it
- Do not upload the wrong file type to `Resource`
- Do not publish without checking mobile and desktop layout on the live page

## When To Escalate
- The page is blank or broken after publishing
- Images do not load
- A button link goes to the wrong place
- A blog post, program, or event does not appear on the website
- You need a new field or a new content section in Sanity

## Handover Checklist
- Sanity roles and permissions configured
- Website editors tested login and publish flow
- Homepage editing walkthrough completed
- Environment variables documented and validated
- Deployment access and rollback steps documented

## Admin Runbook
- Weekly: review new content, links, and uploaded files
- Monthly: review CMS roles, form routing, and dependency updates
- Quarterly: performance, accessibility, and content audit
